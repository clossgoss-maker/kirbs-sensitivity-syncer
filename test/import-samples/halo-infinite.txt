FOV Notes:
Set the FOV in the video settings.
If the FOV you set in-game gets changed to a different value, you can set it in the config file instead. The parameter is
"spec_control_field_of_view": {
    "version": 0,
    "value": XXX
},
(Replace XXX with your FOV), and the he config file is
%LOCALAPPDATA%\HaloInfinite\Settings\SpecControlSettings.json for Steam,
%LOCALAPPDATA%\Packages\Microsoft.254428597CFE2_8wekyb3d8bbwe\LocalCache\Local\HaloInfinite\Settings\SpecControlSettings.json for Microsoft Store.
